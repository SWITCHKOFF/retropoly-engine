# rotating_cube — демо MVP (веха M7, Спринты 17–18)

Финальная демка движка: эталонный W1-ворклоад — **4 видимых куба
(48 текстурированных треугольников)** двумя башнями, фиксированная камера,
`RotationSystem` (90°/сек), AABB-коллизии с выталкиванием, гравитация и
прыжок (demo-level), vertex lighting (ambient + directional) с Gouraud.

Норматив: `docs/plans/sprint_17_18.md`; родительский план —
`docs/DEVELOPMENT_PLAN.md` (§5, M7).

## Запуск (PC)

    cmake --preset pc-release && cmake --build --preset pc-release
    build/pc-release/game/rotating_cube          # интерактив
    build/pc-release/game/rotating_cube 600      # bench 600 с (стресс недели 36)

Управление: **Space** (или **Крестик** геймпада) — прыжок всех кубов,
**TAB** (или **Select** геймпада) — debug overlay (FPS / треугольники / RAM),
**ESC / START** — выход. Камера фиксированная (эталонная расстановка —
управление камерой недоступно по плану демки).

## Сцена W1 (эталонная расстановка)

| Элемент | Значение |
|---|---|
| Кубы | 4 × `cube.mesh` (12 треугольников, 24 вершины) = 48 треугольников |
| Башни | 2 × (2 куба): низ на полу (центр y=1), верх на нижнем (центр y=3) |
| Расстановка | X = ±2.2, Z = 0; зазор между башнями 2.4 |
| Текстуры | по одной CI8 256×256 на куб (`texture_0.tex`..`texture_3.tex`) |
| Камера | фикс. (0, 3.2, 7), pitch −0.15, FOV 70°, near 1, far 100 |
| Режим | CI8/256-палитра, Gouraud on, transparency off |

Меш **один** на 4 куба (W1-геометрия однородна; переиспользование через
`MeshRenderer::mesh_id 0` держит RAM-бюджет — дублирование геометрии не
нуждается). Текстур — четыре варианта (паттерн-перестановки каналов,
по 65 536 уникальных цветов — стресс Median Cut ≤256), генератор —
`scripts/make_source_assets.py`.

## Физика (demo-level, НЕ полноценная физика)

- **Гравитация** −9.8 ед/с² на fixed 16.16 (`rc_gravity_and_jump`, фаза
  GameUpdate тика 60 Гц).
- **Прыжок**: импульс +4.9 ед/с (подъём 1.225 ед — верхние кубы не покидают
  кадр); удержание кнопки — непрерывные подпрыгивания (без grounded-автомата).
- **Коллизии** (`game/systems/collision_system.h`): парное AABB — тест
  пересечения + выталкивание по оси минимального проникновения (ничья —
  приоритет X→Y→Z); скорость по оси выталкивания обнуляется только «в
  поверхность» (скольжение вдоль стен сохраняется). Двигается только
  динамика (со `Velocity`); статика (пол) неподвижна. Пары D-vs-D —
  первый в dense-порядке.
- **Детерминизм**: вся арифметика fixed 16.16 (насыщающая), dense-порядок
  обхода; реплей 60 Гц даёт байт-в-байт те же позиции
  (`tests/ecs/collision_test.cpp`).

## Bench-режим и FPS-лог

`rotating_cube <секунды>` — bench: автоматический выход, лог каждую секунду
(`fps=N (окно M)`), финальный итог **мин/макс/средн** — протокол замера W1
(ворота: PC ≥ 60 FPS, PS1-эмулятор ≥ 30 FPS). Снапшот окружения —
`docs/benchmarks/reference_environment.yaml`.

## Ассеты и сборка

Источники: `assets/source/cube.gltf`, `assets/source/texture_{0..3}.png`
(детерминированный генератор `scripts/make_source_assets.py`); артефакты
`assets/build/*.mesh/.tex` конвертируются целью `convert_assets` /
`convert_rotating_cube_assets` (CMake, PC-конфигурация) и коммитятся как
versioned-ассеты (PS1-checkout). Форматы — `.mesh`/`.tex` v1 (`docs/ASSETS.md`).
