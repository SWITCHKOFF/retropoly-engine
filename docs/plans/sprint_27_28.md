## Задачи

**Неделя 53 — VDP1-фундамент:**

- [ ] [B] Проверить и зафиксировать карту VDP1 VRAM: framebuffer, command table, texture area, CLUT area; точные размеры/выравнивание — по первоисточникам
- [ ] [B] Command list: связанные команды, end-маркер, проверка переполнения; детерминированный порядок; silent drop запрещён
- [ ] [B] Texture upload: 8bpp CI8 + 256-entry CLUT; 4bpp — опционально; максимум 256×256; DMA или CPU-копия с корректным выравниванием
- [ ] [B] ADR-010: политика triangle→quad. Определить детерминированное преобразование (например, вырожденный quad или явное правило упаковки), артефакты и тесты; не менять `.mesh` v1
- [ ] [B] Depth/order: Painter's algorithm, без Z-буфера; порядок команд и tie-breaker для равной глубины

## Риски

- **Артефакты triangle→quad.** Митигация: явная политика, golden-тесты, сравнение с эталоном; не менять `.mesh` v1.
- **Fillrate VDP1.** Митигация: меньше overdraw, бюджет команд, ранний benchmark.
- **VRAM/CLUT.** Митигация: статическая карта, выравнивание, проверка переполнения, отказ от лишних форматов.
- **Различия эмулятора и железа.** Митигация: pinned-эмулятор, документировать, что v0.2.0 — emulator validation, не real-hardware claim.
