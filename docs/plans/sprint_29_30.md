## Задачи

**Неделя 57 — VDP2-фундамент:**

- [ ] [B] Проверить и зафиксировать карту VDP2 VRAM: pattern name table, bitmap/pattern data, palette, scroll registers; разрешение 320×224
- [ ] [B] Один NBG-слой (bitmap) с прокруткой: загрузка фона, палитра, priority; детерминированная инициализация
- [ ] [B] VDP2-регистры: display enable, backdrop, screen size, scroll offsets; сброс при shutdown
- [ ] [B] Тесты: слой виден, scroll offset применяется, wrap корректен, палитра не повреждена
- [ ] [B] Документация: `docs/SATURN.md` — карта VDP2 и ограничения

**Неделя 58 — Композитинг и синхронизация:**

- [ ] [B] Композитинг VDP1 поверх VDP2: priority, прозрачные пиксели, порядок слоёв; без Z-буфера
- [ ] [B] VBlank-синхронизация: переключение VDP1 framebuffer, обновление VDP2, отсутствие tearing
- [ ] [B] Связь камеры и scroll: fixed-point → VDP2-регистры; детерминизм при повторном прогоне
- [ ] [B] Golden композитного кадра: фон + 3D-объект; сравнение между прогонами
- [ ] [B] Диагностика: переполнение VRAM, неверная палитра, недоступный слой — `false` + сообщение

**Неделя 59 — Сцена и ассеты:**

- [ ] [B] Демо-сцена: фон (небо/пол) + 3D-объект; приоритеты и перекрытия проверены
- [ ] [B] Ассет-пайплайн: фоновая текстура 256×256 → VDP2 bitmap; палитра; не ломать `.tex` v1
- [ ] [B] Производительность: VDP2 fillrate/VRAM, стоимость обновления scroll; baseline в `docs/benchmarks/saturn_reference_environment.yaml`
- [ ] [H] Параллакс/второй слой — только если остаётся бюджет; иначе [M] на post-v0.2.0
- [ ] [B] Тесты malformed/overflow для VDP2-ассетов

**Неделя 60 — Гейт:**

- [ ] [B] 10-минутный стресс композитной сцены в pinned-эмуляторе; отсутствие tearing/hang
- [ ] [B] Golden и скриншот; сравнить с PC/PS1, задокументировать отличия
- [ ] [B] CI: `build-saturn.yml` зелёный; артефакт образа; PC/PS1 не регрессировали
- [ ] [B] CHANGELOG + документация; гейт: VDP1+VDP2 синхронизированы, фон виден, priority корректен

## Критерии приёмки спринта 29–30

- [ ] Фоновый слой VDP2 виден за 3D-объектом; priority и прозрачность корректны
- [ ] VDP1+VDP2 синхронизированы; в 10-минутном прогоне нет tearing/hang
- [ ] Композитный golden стабилен; отличия от PC/PS1 объяснены
- [ ] VRAM/палитра/scroll укладываются в бюджет; ошибки возвращают диагностику
- [ ] PC/PS1 сборки и тесты зелёные

## Риски

- **Сложность VDP2.** Митигация: один NBG-слой в v0.2.0, без спецэффектов; расширение — после приёмки.
- **Синхронизация VDP1/VDP2.** Митигация: ранний прототип композитинга, VBlank-контракт, golden.
- **VRAM/палитра.** Митигация: статическая карта, проверки переполнения, минимальный набор форматов.
- **Scope creep.** Митигация: параллакс/второй слой — только [H]/[M], не блокируют v0.2.0.
