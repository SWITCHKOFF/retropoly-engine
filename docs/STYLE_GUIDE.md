# STYLE_GUIDE — RetroPolyEngine

> Нормативно: `docs/plans/sprint_01_02.md` (Неделя 1, задача [B]) и
> `docs/RetroEngine_Engineering_Documentation_v1.43.md` (нормативные секции
> имеют приоритет над этим файлом при расхождении).
> Автоформатирование: `.clang-format` в корне репозитория (правила этого гайда).

## 1. Именование

| Сущность | Правило | Пример |
|---|---|---|
| Классы, структуры, типы (typedef/using) | `PascalCase` | `Vec3`, `Mat4`, `LinearAllocator` |
| Функции, методы | `snake_case` | `fixed_mul`, `mat4_identity` |
| Поля классов (с инкапсуляцией) | `m_префикс` + `snake_case` | `m_length`, `m_component_mask` |
| Константы (`constexpr`, `const` в зоне файла, enum values) | `UPPER_SNAKE` | `MAX_ENTITIES`, `FIXED_ONE` |
| Макросы | `UPPER_SNAKE` с префиксом домена | `FIXED_BITS`, `PLATFORM_PC` |
| Локальные переменные, параметры | `snake_case` | `angle`, `near_z` |
| Файлы | `snake_case`, расширение по содержимому | `fixed.h`, `fixed.cpp` |

**Исключение (normative API):** публичные POD-структуры ядра, чей layout
зафиксирован нормативной документацией (§4.2–4.3: `Vec2/Vec3/Vec4` поля
`{x,y,z,w}`, `Mat4` поле `m[16]`), сохраняют имена полей без `m_`-префикса:
их двоичное представление — контракт, а не инкапсуляция.

## 2. Форматирование

- Отступ: **4 пробела**, табуляция запрещена; перевод строк **LF**; кодировка **UTF-8 без BOM**.
- Длина строки: **≤ 100 символов** (жёсткий лимит, не мягкий).
- Фигурные скобки: та же строка (K&R / Attach); для функций — также на той же строке.
- Одна операция на строку; запрещены несколько присваиваний в одной строке.
- Заголовки защищаются `#pragma once` (не классические include-guard'ы).
- Порядок включений: (1) собственный заголовок, (2) заголовки проекта
  (`"core/math/fixed.h"` — путь от `src/`), (3) third-party, (4) стандартная библиотека,
  с пустой строкой между группами.

## 3. Ограничения языка (runtime-код движка)

- **`auto` запрещён в публичном API** (заголовки публичных интерфейсов: явные типы
  в сигнатурах и в телах inline-функций публичного API). В приватных `.cpp`
  `auto` уместен для очевидных итераторов/инициализаций.
- **`using namespace` запрещён в заголовках** — полностью; в `.cpp` допустим
  только узкий `using` конкретных имён.
- **`new`/`delete` и `malloc`/`free` запрещены в runtime** (нормативно §1
  «Явное управление памятью»): все аллокации — через аллокаторы ядра
  (`src/core/memory`, Спринты 3–4) в заранее ограниченных аренах/пулах.
- **`printf`/`puts`/`std::cout` и прочий прямой ввод-вывод запрещены в runtime движка.**
  Диагностика — исключительно через `src/core/log` (логгер, Спринты 3–4).
  Тесты используют средства GoogleTest.
- **Плавающая точка запрещена в игровой логике** (детерминированность §1.4).
  Единственные допустимые точки: конверсии `fixed_from_float/fixed_to_float`,
  host-only инструменты (`tools/asset_converter`, сборка ассетов) и **тесты**
  (эталонные модели в `double` для проверки точности).
- Никаких исключений (`throw`) в runtime ядра: ошибки — статус-код + детерминированный
  диагностический код (нормативная секция Failure policy).
- Никакого UB по знаковому переполнению: все промежуточные вычисления — в `int64_t`
  с явным насыщением (`fixed_clamp_i64` и аналоги).

## 4. Комментарии и документация

- **Doxygen обязателен для всех публичных функций** (`@param`, `@return`;
  насыщающее поведение, детерминизм, недопустимые входы указываются явно).
- Комментарии (русский и английский допустимы; не смешивать языки внутри одного
  блока). Назначение и инварианты важнее повторения сигнатуры.
- В начале каждого файла — SPDX-заголовок лицензии MIT (см. существующие файлы).

## 5. Тесты (tests/)

- Один suite на модуль: `TEST(Fixed, ...)`, `TEST(Vec3, ...)`, `TEST(Mat4, ...)`;
  имена кейсов — `PascalCase` без глаголов-служебных (например,
  `SaturatingArithmetic`, `ReductionUsesSingleFinalClamp`).
- Эталонные значения вычисляются независимо (ручная математика / `double`-модель),
  а не той же функцией движка.
- Детерминизм проверяется на **raw-значениях** (`fixed_t`), а не только через `float`.

## 6. Коммиты

- Атомарные: один логический шаг = один коммит (модуль, тесты к нему, документация).
- Сообщения на русском/английском по образцу истории репозитория,
  первая строка ≤ 72 символов, затем пустая строка и пояснение.
